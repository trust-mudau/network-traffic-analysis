# Project Checklist

## Phase 1 — Setup
- [ ] Install Wireshark
- [ ] Confirm Npcap is installed on Windows
- [ ] Identify active network interface
- [ ] Create GitHub repository
- [ ] Add starter files

## Phase 2 — Capture Normal Traffic
- [ ] Record local IP address
- [ ] Capture DNS traffic
- [ ] Capture ICMP traffic
- [ ] Capture TCP connection
- [ ] Capture HTTP traffic
- [ ] Capture HTTPS/TLS traffic
- [ ] Save capture as PCAPNG

## Phase 3 — Analyze
- [ ] Explain DNS query and response
- [ ] Explain TCP SYN, SYN-ACK, ACK
- [ ] Explain ICMP echo request/reply
- [ ] Compare visible HTTP data with encrypted TLS traffic
- [ ] Record important source/destination IPs
- [ ] Take useful screenshots

## Phase 4 — Security Investigation
- [ ] Identify top communicating endpoints
- [ ] Look for repeated failed/retried connections
- [ ] Identify unexpected protocols
- [ ] Explain whether observed traffic appears normal
- [ ] Document limitations

## Phase 5 — Portfolio Polish
- [ ] Complete README findings
- [ ] Remove sensitive/private information from screenshots
- [ ] Ensure no credentials or tokens are committed
- [ ] Add final investigation report
- [ ] Add architecture/network diagram
- [ ] Pin repository on GitHub
