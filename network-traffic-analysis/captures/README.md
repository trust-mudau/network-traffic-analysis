# Packet Captures

Store authorized lab captures here.

Recommended naming format:

```text
YYYY-MM-DD-normal-traffic.pcapng
YYYY-MM-DD-dns-test.pcapng
YYYY-MM-DD-icmp-test.pcapng
```

Before publishing a PCAP/PCAPNG file publicly, consider whether it contains sensitive information such as hostnames, cookies, authentication data, private communications, public IP information, or traffic belonging to other people.

When in doubt, document the analysis with sanitized screenshots instead of uploading the raw capture.
