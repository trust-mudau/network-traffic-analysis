# Network Traffic Analysis with Wireshark

## Project Overview

This project demonstrates foundational network-security analysis using Wireshark.

The objective is to capture traffic generated by my own lab/device, identify common network protocols, explain how the traffic works, and document security-relevant observations.

## Skills Demonstrated

- TCP/IP fundamentals
- DNS analysis
- TCP three-way handshake analysis
- ICMP analysis
- HTTP/HTTPS traffic analysis
- Wireshark display filters
- Packet inspection
- Basic security investigation
- Technical documentation

## Investigation Objectives

1. Capture traffic from an authorized device/network.
2. Identify DNS requests and responses.
3. Identify a TCP three-way handshake.
4. Identify ICMP echo requests and replies.
5. Compare HTTP and HTTPS/TLS traffic.
6. Use display filters to isolate relevant packets.
7. Document observations and security implications.
8. Produce a short final investigation report.

## Key Wireshark Filters

```text
dns
icmp
tcp
http
tls
tcp.flags.syn == 1
tcp.flags.syn == 1 && tcp.flags.ack == 0
ip.addr == YOUR_IP
```

See `filters/wireshark-filters.md` for more.
